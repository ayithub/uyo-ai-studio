# Uyo

Uyo is a browser-based AI studio for image generation, photo editing, and video creation.

## Features

- Text to image and image to image generation
- AI photo editing, image upscaling, and background removal
- Text to video and image to video creation
- Credit cost estimates shown before generation
- My Creations keeps tasks and results in one workspace
- English and Chinese interfaces

## Links

- Website: https://uyo.io/
- Create image: https://uyo.io/create/image
- Make videos: https://uyo.io/create/video
- AI tools: https://uyo.io/tools
- Pricing: https://uyo.io/pricing

Generation requires an account and sufficient credits. One-time credit packs are listed on the pricing page.
